# 第一版选题说明

核对日期：2026-10-28。以第一次公开的论文/技术报告日期排序，主要范围从 2026-07-01 开始。

## 建议的阅读主线

1. **ENPIRE**：真实机器人上的 reset–execute–verify–refine 循环；策略代码和训练程序都可以成为改进对象。注意项目页的 99% 为带自适应重试的 pass@8，不是单次成功率。
2. **ASPIRE**：把执行轨迹中的经验积累为可调用的 /skills。与 ENPIRE 一起作为用户指定的六月基础工作，明确标记，不改写成七月首发。
3. **WorldScape-R²SI**：Robot Agent 与 Recursion Agent 双层系统，把技能/harness 修订与 reactive model 训练放到一个循环里。报告日期为 10 月 24 日，系统项目于 10 月 17 日公布。
4. **EmbodiedEvo、HexaShell、SERA**：分别关注 Skills/Lessons、可复用工具、规划 harness 的持久改进。区分开发时演化与测试前冻结。
5. **RSI-Nav**：覆盖导航方向，以当前策略生成和过滤指令，递归更新导航与语言能力。
6. **SEAR、PhysRSI-Eval**：判断增益究竟来自可保留的经验、额外重试还是评测预算，适合配合方法论文阅读。

所有条目的精确标题、首发日期、实验说明、链接和核心图来源在 `data/catalogue.json`。

## RoboDojo 榜单如何使用

当前快照取自官方 Sim 的 Agent 分类，按 Average Score 排序。Score 衡量任务进展，Success Rate 是另一个指标。榜单与论文实验可能使用不同版本，不能相互替换。

- GO-3 Nano Preview：保留官方排名，没有编造尚未核实的论文或 RSI 环节。
- PyRUA-Lean：保留为 `Leaderboard reference`，其高效在线执行本身不能证明有持久自改进。
- HexaShell-Preview、WorldScape-R²SI、EmbodiedEvo：既保留榜单快照，也收录其明确说明自改进机制的论文。
- PhysicalRSI：作为前五以外的补充基线留在 JSON 快照，不把研究博客自动当作独立论文。

快照同时保存 `checked_at`、官方 bundle 声明的 `updated_at`、最新新闻日期和原始 bundle SHA-256。声明时间戳早于新闻日期，因此没有将其当作严格的数据最新时间。
