# 使用与部署

本仓库专门整理 Robot Recursive Self-Improvement（机器人递归自我改进）：机器人执行产生反馈，反馈驱动策略、技能、代码或 harness 的持久改进，再重新评估。

## 内容维护

- 编辑 `data/catalogue.json`，然后运行 `python3 website/build.py`，同时更新 README 和网站。
- `date` 使用第一次公开发布日期，不用论文修订日期替代。
- 以 2026-07-01 之后的工作为主；ENPIRE 和 ASPIRE 是明确标记的六月基础工作。
- 每篇使用作者论文或项目里的核心方法图，并记录 `figure.source`、`figure.credit`。
- `links` 中 Paper、Code 优先；不存在 Data、Models 时省略相应字段。
- RoboDojo 榜单是带日期的官方快照。Score 不等于成功率，榜单排名也不自动证明该方法属于 RSI。

## 本地构建

只需要 Python 3，无需数据库、API 密钥或前端安装。

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
python3 website/build.py
python3 -m http.server 8000 --directory website/dist
```

在运行命令的电脑打开 http://localhost:8000。如果命令运行在远程云环境，需要相应的端口转发。

## GitHub Pages

1. 将仓库放到自己的 GitHub 账号下。
2. `Settings → Pages → Build and deployment → Source` 选择 `GitHub Actions`。
3. 在 `Actions → Build and deploy catalogue` 中手动运行，或向 `main` 推送内容。
4. 默认网址为 `https://<用户名>.github.io/awesome-robot-RSI/`。

GitHub Actions 会检查内容、构建静态站点，再发布 `website/dist`。网站使用相对资源路径，支持项目子目录。

如果更换账号或仓库名，同步修改 `data/catalogue.json` 的 `repository`。本版本没有继承原仓库作者的 Google Analytics、访问量计数器或收费数据更新任务。
